# Limitations

The browser and Wokwi builds use simulated inputs. The event log stays in one browser and can be edited, so it is not tamper-resistant. The firmware does not include a production network, watchdog, emergency stop, or tank-level interlock. Power-loss diversion still needs a normally safe valve and a physical test. ChromaGuard has no trained ML model, field calibration, regulator approval, or treatment results.
