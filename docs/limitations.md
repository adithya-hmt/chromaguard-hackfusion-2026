# Limitations

This release is a digital twin and Wokwi demonstration. Sensor values are simulated, the firmware has no production-grade networking or safety interlock, and the browser log is local to one device. localStorage event records are exportable but not tamper-evident. Power-loss diversion is not proven by the current virtual hardware and would require a normally-safe valve, independent energy/state design, and physical validation. There is no trained ML model, regulator certification, SaaS backend, or claim that the prototype authorizes discharge.
