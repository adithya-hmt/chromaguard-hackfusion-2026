# Demo script

1. Open the dashboard and point out the live sensor pod and rule-based score.
2. Choose **Normal compliant discharge**; show the green normal route and event log.
3. Choose **High TDS violation**; show automatic red diversion and holding-tank volume.
4. Choose **Sensor disconnected**; show fail-safe fault diversion.
5. Enable maintenance bypass; show the visible maintenance state and logged override.
6. Restore normal readings twice; show consecutive compliant samples release the valve.
7. Export the CSV and open the Wokwi Serial Monitor for matching JSON telemetry.
